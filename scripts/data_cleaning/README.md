# Python Data-Cleaning Scripts

This directory is reserved for Python scripts that transform raw job-advertisement files into interim and processed outputs.

Planned responsibilities include column validation, duplicate detection, role and skill normalization, location and work-mode standardization, and salary parsing where supported. Read from `data/raw/`; write to `data/interim/` or `data/processed/`. Never overwrite the original source files.

No cleaning code has been created yet. Define the exact transformations after completing the data audit and data dictionary.
