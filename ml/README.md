# Machine Learning

This directory separates each modeling task and shared evaluation evidence.

- [`skill_matching/`](skill_matching/README.md): explainable skill-to-job matching baseline.
- [`clustering/`](clustering/README.md): discovery of job groups by skill or text similarity.
- [`classification/`](classification/README.md): job-family classification, subject to reliable labels.
- [`regression/`](regression/README.md): salary modeling, subject to sufficient comparable disclosed salaries.
- [`evaluation/`](evaluation/README.md): baselines, metrics, model cards, and review evidence.

See `docs/ML_PLAN.md`. Do not expose model output to users until its quality gate passes.
