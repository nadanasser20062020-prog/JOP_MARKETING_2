# Model Evaluation

Store shared baselines, evaluation summaries, model cards, and review evidence here. Every result identifies its dataset version, target/feature definition, split or sampling approach, metrics, error/stability review, and limitations. Use `docs/software-engineering/MODEL_CARD_TEMPLATE.md` for models considered for user-facing use.

The current [skill-profile clustering evaluation](results/SKILL_PROFILE_CLUSTERING_EVALUATION.md) is an offline exploratory report only. It is not proof of occupational categories and has no serialized model artifact. Predictive salary and job-family models remain no-go pending comparable labels, provenance, representative reviewed samples, and evaluation criteria.
