# Raw Data

Place authorized, unchanged copies of collected source files here only when a local copy is needed.

- Treat these files as immutable inputs; do not clean or overwrite them.
- The original Drive files remain the source of record.
- Data files in this directory are excluded from Git. Do not commit raw CSV, ZIP, or other dataset files.
- Record source, collection date, and file checksum in the data-audit documentation when available.
