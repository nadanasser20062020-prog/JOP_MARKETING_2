# Analytics

This directory contains SQL analysis, Python exploratory analysis, charts, and reports.

- [`sql/`](sql/README.md): documented, reproducible analytical queries.
- [`notebooks/`](notebooks/README.md): Python analysis using Pandas, NumPy, Matplotlib, and Seaborn.
- [`reports/`](reports/README.md): reviewed results, charts, sample sizes, and limitations.

Start with `docs/ANALYTICS_PLAN.md`. Keep credentials and raw datasets out of the repository, and reconcile published metrics against their source queries.
