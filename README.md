# JOP Marketing Intelligence

**منصة تحليل واكتشاف لسوق الوظائف** تساعد المهندسين في مصر والدول العربية على استكشاف إعلانات الوظائف في الأسواق العربية والأجنبية، وفهم المهارات المطلوبة، ومقارنة الفرص، ومعرفة المهارات التي قد يحتاجون إلى تطويرها.

## حالة المشروع

- حسب وصف الفريق: **تم جمع البيانات فقط**؛ لم يبدأ تنظيفها أو تحليلها أو بناء الموقع والنماذج.
- هذا التحديث يضيف **خطة التنفيذ وهيكل المستودع فقط**، ولا يضيف كودًا للتطبيق أو يغيّر ملفات البيانات.
- محتوى ملفات Drive وأعمدتها لم يتم التحقق منه بعد؛ لذلك الميزات التي تحتاج أعمدة معينة تعتمد على نتيجة تدقيق البيانات.

## نطاق الميزات المتفق عليه

- لوحة مؤشرات لسوق العمل، والبحث عن الوظائف وتصفية الإعلانات وعرض تفاصيلها ومصدرها.
- تحليل الطلب على الوظائف والمهارات والشركات، وتحليل الرواتب وأنماط العمل عندما تسمح البيانات بذلك.
- مقارنة الأسواق، وعرض الاتجاهات عبر الوقت إذا توفرت تواريخ مناسبة، واستكشاف ترابط المهارات والوظائف.
- إدخال مهارات المستخدم، وترتيب الوظائف أو المسارات المهنية الأقرب لها، وشرح المهارات المطابقة والناقصة.
- ربط المهارات الناقصة بمصادر تعلم مجانية موثوقة.
- واجهة عربية وإنجليزية، مع مراعاة اتجاه العربية وتوحيد المسميات والمرادفات.
- تطبيق التحليل بـ SQL وPython، وبناء ERD، وتجربة clustering وclassification وregression وفق جودة البيانات.

### خارج النطاق حاليًا

- حفظ الوظائف أو عمليات البحث.
- التنبيهات والإشعارات عن وظائف جديدة.

## مبدأ أساسي

كل نتيجة في الموقع أو التحليل يجب أن توضّح أنها مبنية على **عينة إعلانات الوظائف المتاحة للفريق**، مع بيان عدد السجلات ومصدرها وتاريخها عند توفره. الإعلان لا يمثل بالضرورة كل سوق العمل، والراتب أو المهارة غير المذكورة لا تُعامل كأنها صفر أو معلومة مؤكدة.
