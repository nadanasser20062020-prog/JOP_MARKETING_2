# Software Engineering Documentation

This section defines the product and engineering baseline for JOP Marketing Intelligence. It covers requirements, user behavior, architecture, interfaces, data storage, security, quality, and delivery.

## Document Status

These documents are design specifications, not implementation. The dataset schema, technology stack, hosting provider, and operational targets are not yet confirmed. Requirements that depend on those decisions are explicitly provisional or conditional. Finalize them after the dataset audit and team review.
